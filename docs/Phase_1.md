# فاز ۱: محاسبه سایش attachmentها (بدون deep learning)

پردازش mesh سه‌بعدی دندان‌ها با روش هندسی، برای محاسبه **درصد سایش attachmentها** از مقایسه دو اسکن T1 و T2.

## داده

- فایل‌های `STL` از مدل سه‌بعدی فک بالا
- هر فایل شامل ۱۴ دندان است
- از هر مدل دو نسخه وجود دارد:
  - `T1`: قبل
  - `T2`: بعد

## ابزارها

- Python
- `open3d`
- `trimesh`
- `scikit-learn`

```bash
pip install open3d trimesh scikit-learn
```

## مراحل

### ۱. هم‌ترازی T1 و T2

1. روی هر مدل دو نقطه به‌صورت دستی انتخاب می‌شود، از جاهایی که attachment ندارند.
2. این نقاط ورودی هم‌ترازی اولیه هستند.
3. الگوریتم ICP در `open3d` دو مدل را به‌صورت خودکار روی هم می‌اندازد.

### ۲. جداسازی attachmentها

- تشخیص با روش انحنا (curvature)
- خوشه‌بندی با DBSCAN، با `open3d` یا `scikit-learn` (یکی از دو)

### ۳. حجم سایش

- محاسبه حجم با `trimesh`
- مقایسه حجم attachmentها بین T1 و T2 و به‌دست آوردن درصد سایش
